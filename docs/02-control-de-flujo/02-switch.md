Switch:

Lo Utilziamos cuando tenemos varias opciones y dependiendo la eleccion o condicion que decidamos
ejecute la instruccion, mayormente la usaremos en creacion de menu con multiples opciones.

ejemplo:

int menu = 1

switch (menu) {
    case 1:
        System.out.printl("Pizza Peperoni")
        break;
    case 2:
        System.out.printl("Pizza Peperoni")
        break;
    case 3:
        System.out.printl("Pizza Peperoni")
        break;
    case 4:;
        System.out.printl("Pizza Peperoni")
        break;
    case 5:
        System.out.printl("Pizza Peperoni")
        break;
    default:
        System.out.printl("Ingrese un numero")

}
