* repetitivo BUCLES - (for, while, do while)
Repite bloques de codigo mientras se cumpla una condicion.
ejemplo:

* 1 - Elegimos el bucle a usar: (for)
* 2 - Declaramos la variable: int = 1
* 3 - Escribimos la condicion que debe cumplirse: i <= 5;
* 4 - Contador a condicion de corte: i++ o la variable que elijamos.
            |
for (int = 1; i <= 5; i++){
    System.out.println("Numero: " + i);
}

los usaremos dependiendo el caso que necesitemos.
